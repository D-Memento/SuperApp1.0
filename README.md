# SuperApp

 SuperApp — файловый менеджер для Linux

SuperApp — графический файловый менеджер на Java (Swing) с быстрым доступом к документам, корзине, системной папке и подключаемым устройствам.

 Что умеет программа

- Древовидная навигация по разделам:
  - Мои документы
  - Корзина
  - System
  - Съёмные устройства
- Карточный просмотр содержимого папок в правой панели.
- Поиск файлов и папок по имени.
- Контекстные действия:
  - создать файл/папку,
  - открыть,
  - копировать/вставить,
  - переименовать,
  - удалить в корзину,
  - восстановить из корзины,
  - очистить корзину,
  - посмотреть свойства.
- Drag & Drop для работы с файлами.
- Горячие клавиши (в разделе «Справка»):
  - `Ctrl + N` — создать файл,
  - `Ctrl + D` — удалить файл,
  - `Ctrl + R` — восстановить,
  - `Ctrl + T` — очистить корзину,
  - `F1` — информация о программе.
- Встроенный терминал и всплывающее окно с системной информацией.
- Пункт «Устройства» для ручного обновления списка подключённых носителей.

---
 Где хранятся рабочие папки

При старте рядом с приложением используются/создаются каталоги:

- `Мои документы`
- `Корзина`
- `System`

Это удобно для локальной работы и тестирования, так как не затрагивает системные каталоги пользователя.

---

 Полезные замечания

- Для некоторых системных утилит из меню (например, `gnome-system-monitor`) нужна соответствующая среда рабочего стола и установленные пакеты.
- Если утилита недоступна, программа покажет сообщение об ошибке — это нормально.

## Как работать с проектом

Maven сам умеет:

- собирать проект
- запускать программу
- собирать исполняемый jar

Исходники остаются в `System/src/main/java`, Maven берет их оттуда через настройку `sourceDirectory` в `pom.xml`.

---

## Требования

- Java 21
- Maven 3.9+

## Команды

Собрать jar:

```bash
mvn clean package
```

После этого jar будет лежать в:

```bash
target/SuperApp.jar
```

Собрать и сразу запустить программу через Maven:

```bash
mvn clean package exec:java
```

Быстрый запуск без упаковки jar:

```bash
mvn compile exec:java
```

## Что настроено в pom.xml

- `maven-compiler-plugin` компилирует проект под Java 21
- `exec-maven-plugin` запускает главный класс `filesystem.MainWindow`
- `maven-shade-plugin` собирает готовый `target/SuperApp.jar` со всеми зависимостями

Отдельный shell-скрипт для запуска больше не нужен: Maven умеет и собирать, и запускать проект сам.
